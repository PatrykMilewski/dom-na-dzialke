# Własny kawałek — porównanie projektów domów

Statyczna porównywarka po polsku: filtry, ulubione zapisane lokalnie, porównanie do czterech projektów, szczegóły dopasowania i wspólny model kosztów.

Źródła, zakres powierzchni i ograniczenia analizy są podane przy projektach. To wstępna selekcja, nie projekt zagospodarowania ani kosztorys ofertowy. Wizualizacje pobierane są z witryn autorów i należą do wskazanych pracowni.

Podgląd: `python3 -m http.server 8765 --directory dist`.
GitHub Pages publikuje katalog `dist` przez workflow.
